# Выпуск версии

Используем теги `vMAJOR.MINOR.PATCH`, например `v0.1.0`. До версии 1.0 минорный номер может включать несовместимые изменения. Предварительный выпуск обозначается как `v0.2.0-rc.1` и автоматически помечается prerelease.

1. Подготовьте изменения в `main`. Перенесите записи `Unreleased` под заголовок `## [0.1.0] - YYYY-MM-DD` с фактической датой и создайте новый пустой `Unreleased`. Для последующих выпусков подставьте нужный номер.
2. Проверьте описание и локальную упаковку:

   ```sh
   python3 scripts/release.py notes --version v0.1.0
   make dist VERSION=0.1.0
   ```

3. Закоммитьте изменения и отправьте `main`. Дождитесь успешного CI.
4. Создайте и отправьте тег на проверенном коммите:

   ```sh
   git tag -a v0.1.0 -m 'sshm v0.1.0'
   git push origin v0.1.0
   ```

Workflow `Release` повторяет CI, проверяет принадлежность коммита истории `main`, берёт описание из раздела версии в changelog и публикует GitHub Release. Без соответствующего раздела публикация остановится. Релиз сначала создаётся как черновик и публикуется после загрузки всех assets; повторный запуск может завершить оставшийся черновик. Уже опубликованный релиз workflow не перезаписывает. Архивы содержат `sshm`, README, лицензию и changelog; рядом публикуется `checksums.txt`. Версия встроена в бинарник и доступна через `sshm -version`.

Для автоматизации используется встроенный `GITHUB_TOKEN`; отдельный персональный токен не нужен. В репозитории должны быть разрешены GitHub Actions. Право `contents: write` получает только задача публикации. Dependabot предлагает обновления Go-зависимостей и Actions отдельными pull request.

Не перемещайте опубликованные теги и не заменяйте assets выпущенной версии. Если проверка или сборка упала до создания релиза, исправьте причину и повторите workflow; если релиз уже опубликован, выпустите новую patch-версию.

Архивы macOS пока не имеют Developer ID-подписи и нотариализации Apple. При блокировке запуска разрешите запуск проверенной сборки в настройках macOS или соберите приложение из исходников.
