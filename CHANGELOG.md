# История изменений

Здесь описаны изменения, заметные пользователям. Подготовленные изменения находятся в `Unreleased`; опубликованные версии получают номер и дату выпуска.

## [Unreleased]

## [0.1.0] - 2026-10-21

### Добавлено

- Иерархические списки на вкладках «Соединения» и «Папки»: свёрнутый верхний уровень, раскрытие через Enter или пробел, маркеры `▸` / `▾` и поиск с родительскими папками.
- Папки по алфавиту перед соединениями; соединения без папки на верхнем уровне.
- Автоматические проверки, сборка архивов и публикация GitHub Releases по тегу версии.
- Архивы для macOS и Linux на arm64 и amd64 с контрольными суммами SHA-256.

### Первая публичная версия

- Каталоги соединений, папок и профилей аутентификации с наследованием, поиском и файловыми браузерами.
- Зашифрованное хранилище, главный пароль, блокировка и резервные версии.
- Системный OpenSSH с возвратом в TUI, локальные и импортированные ключи, SSH-agent, пароли и интерактивный OTP.
- Объединение правок и отдельных облачных копий с разрешением конфликтов.
- Адаптивный интерфейс для широких и узких терминалов.

### Известные ограничения

- Работа непосредственно на Linux ещё не проверена; Linux-бинарники проходят кросс-сборку.
- При объединении отдельной облачной копии удаления автоматически не распространяются.
- Путь локального ключа должен совпадать на устройствах; локальные сопоставления пока отсутствуют.
